FAQ

Common questions on privacy, compatibility and licensing.

Frequently asked questions

Does it upload my whole log?

No. It is cleaned first (noise removed, stacks folded), personal data is masked and there is a character cap. You can preview before sending. With the local LLM nothing goes to an external server.

Does it support Forge / NeoForge?

Headers are parsed. But Forge / NeoForge latest.log usually has no full mod list; it is only filled in from a crash report when one exists.

Why does the GitHub route use the Copilot CLI?

GitHub Models, which the route used before, was retired on 2026-07-30, and Copilot has no documented public chat endpoint callable with a token. The official programmatic entry point is the Copilot CLI, so the app runs it as a child process.

The local model prints lots of thinking?

That model emits a think block first; the app hides it automatically.

Can I use a different local model?

Yes — change the download URL under Settings → Local LLM → Advanced.

Does it run on macOS / Linux?

It uses Qt and compiles on other platforms (the author built it on Linux with Qt 6.4.2 and launched the UI offscreen), but key encryption relies on DPAPI, so non-Windows platforms refuse to store keys.

Can I use it commercially?

PolyForm Shield allows use, modification and distribution, but not providing a product or service that competes with this software. See the License page; this is not legal advice.
