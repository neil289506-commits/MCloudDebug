Guide

Five steps: pick an instance, choose a provider, preview, send.

  1. Get the app

    Download the Windows build from the download page, unzip it and run MCDebugger.exe.

  2. Choose a Minecraft instance

    Pick the instance that has the problem; the app reads its latest.log and looks for the newest crash report.

  3. Pick an AI provider

    Choose Groq, local LLM or GitHub in settings and enter the matching credentials. See AI Providers for the differences.

  4. Check the preview

    Make sure the cleaned content and masking look right before continuing.

  5. Send and read the diagnosis

    The AI replies with likely causes and fixes based on the cleaned log. Treat it as a hint and verify against the original log.

Setting up each provider

Groq

Create an API key and paste it into settings. It is stored encrypted with DPAPI.

GitHub Copilot

Install the Copilot CLI (npm install -g @github/copilot) and run copilot login, or paste a token in Settings. Needs a Copilot subscription.

Local LLM

Download llama.cpp and the model from settings. The Q4_K_M model is about 5.24 GiB, so reserve disk and RAM.

Tip:GitHub removed the PAT pre-fill feature from its docs in 2026-05, so the link may not fill in the fields. Use the manual steps above.
