Local LLM details

  • The default model is empero-ai/Qwythos-9B-Claude-Mythos-5-1M-GGUF (9B reasoning model, Q4_K_M recommended). To use another model, change the download URL under Settings → Local LLM → Advanced.
  • The model emits <think>…</think> before answering; the app hides it and also handles the case where only </think> appears.
  • Sampling follows the model card: temperature 0.6, top_p 0.95.

How llama.cpp is downloaded

The releases/latest of ggml-org/llama.cpp currently points to a "pointer release" containing only nightly-tag.txt; the real version is inside that file. The app does the following:

  1. HEAD releases/latest to get the pointer tag
  2. Download nightly-tag.txt and read the real version
  3. Build the Windows zip name for Vulkan / CPU / CUDA 12.4 (CUDA also pulls cudart)
  4. Extract with PowerShell Expand-Archive

If nightly-tag.txt is missing, it falls back to the redirect tag.

The GitHub route is GitHub Models

The public inference API reachable with a PAT is GitHub Models, not Copilot Chat. The author found no documented public endpoint for calling Copilot Chat with a PAT, so it is not faked. The model list comes from models.github.ai/catalog/models.
