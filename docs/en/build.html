Build from source

Compile from source with Qt Creator or CMake.

Qt Creator

  1. Open CMakeLists.txt
  2. Pick the Desktop Qt 6.x MSVC2022 64-bit kit
  3. Build and run

Only Qt Widgets and Network are used; on Windows it also links crypt32. The minimum is Qt 6.4.

Command line

git clone https://github.com/neil289506-commits/MCloudDebug.git
cd MCloudDebug
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_PREFIX_PATH="<Qt path>"
cmake --build build --config Release --parallel

Packaging

windeployqt --release --no-translations --compiler-runtime MCDebugger.exe

CI

When a v* tag is pushed, CI builds from source and publishes MCloudDebug-Windows-AMD64.zip to the Release. GitHub Actions builds on windows-2022. Because aqtinstall currently cannot fetch Qt 6.11.x, the workflow tries 6.11.2 / 6.11.3 / 6.11.1 in order and falls back to 6.10.3.
