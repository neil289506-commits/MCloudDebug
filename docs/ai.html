本地 LLM 細節

  • 預設模型為 empero-ai/Qwythos-9B-Claude-Mythos-5-1M-GGUF（9B 推理模型，推薦 Q4_K_M）。若你要的是別的模型，到「設定 → 本地 LLM → 進階」改下載網址。
  • 模型回答前會輸出 <think>…</think>，程式會隱藏，也處理只有 </think> 的情形。
  • 取樣參數採模型卡建議值：temperature 0.6、top_p 0.95。

llama.cpp 如何下載

ggml-org/llama.cpp 的 releases/latest 目前指向一個只含 nightly-tag.txt 的「指標 release」，真正版本寫在該檔內。程式流程如下：

  1. HEAD releases/latest，取得指標標籤
  2. 下載 nightly-tag.txt，讀出真正版本
  3. 依硬體組出 Vulkan / CPU / CUDA 12.4 的 Windows zip（CUDA 另含 cudart）
  4. 用 PowerShell Expand-Archive 解壓

若 nightly-tag.txt 不存在，會退回使用轉址標籤。

GitHub 管道其實是 GitHub Models

PAT 可直接呼叫的公開推論 API 是 GitHub Models，不是 Copilot Chat。作者沒有找到可用 PAT 呼叫 Copilot Chat 的文件化公開端點，所以沒有假裝實作。模型清單來自 models.github.ai/catalog/models。
