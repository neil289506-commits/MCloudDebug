自行建置

用 Qt Creator 或 CMake 從原始碼編譯。

Qt Creator

  1. 開啟 CMakeLists.txt
  2. Kit 選 Desktop Qt 6.x MSVC2022 64-bit
  3. 建置並執行

只用到 Qt Widgets 與 Network，Windows 另外連結 crypt32。專案最低需求為 Qt 6.4。

命令列

git clone https://github.com/neil289506-commits/MCloudDebug.git
cd MCloudDebug
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_PREFIX_PATH="<Qt 路徑>"
cmake --build build --config Release --parallel

發佈用打包

windeployqt --release --no-translations --compiler-runtime MCDebugger.exe

CI

GitHub Actions 在 windows-2022 上建置。因 aqtinstall 目前抓不到 Qt 6.11.x，流程會依序嘗試 6.11.2 / 6.11.3 / 6.11.1，不可用時退回 6.10.3。
