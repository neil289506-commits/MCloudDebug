使用教學

五個步驟：選實例、挑 AI 管道、預覽、送出。

  1. 取得程式

    從下載頁取得 Windows 版並解壓縮，執行 MCDebugger.exe。

  2. 選擇 Minecraft 實例

    選出出問題的實例，程式會讀取它的 latest.log，並找最新的崩潰報告。

  3. 挑一條 AI 管道

    在設定中選 Groq、本地 LLM 或 GitHub，填入對應認證。三條管道的差別見 AI 管道。

  4. 檢查預覽

    確認整理後的內容與遮蔽結果沒問題，再往下一步。

  5. 送出並閱讀診斷

    AI 會根據整理後的 log 回覆可能原因與處理方向。結果僅供參考，建議對照原始 log 驗證。

各管道的準備工作

Groq

建立 API Key 後貼到設定。Key 會用 DPAPI 加密存放。

GitHub Models

建立 Fine-grained PAT：Account permissions → Models → Read-only（models: read）。

本地 LLM

在設定中下載 llama.cpp 與模型。模型 Q4_K_M 約 5.24 GiB，請預留硬碟與記憶體。

提示：預填 PAT 連結的功能已被 GitHub 在 2026-05 從文件移除，連結可能不會自動帶入欄位，請依上面的手動步驟設定。
