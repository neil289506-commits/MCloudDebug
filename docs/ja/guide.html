使い方

5 ステップ：インスタンス選択、プロバイダー選択、プレビュー、送信。

  1. アプリを入手

    ダウンロードページから Windows 版を入手して解凍し、MCDebugger.exe を実行します。

  2. Minecraft インスタンスを選択

    問題のあるインスタンスを選ぶと、latest.log を読み込み、最新のクラッシュ報告も探します。

  3. AIプロバイダーを選ぶ

    設定で Groq・ローカルLLM・GitHub のいずれかを選び、認証情報を入力します。違いは AIプロバイダー を参照してください。

  4. プレビューを確認

    整理結果とマスクに問題がないことを確認してから次へ進みます。

  5. 送信して診断を読む

    AI が整理後のログから考えられる原因と対処方針を返します。あくまで参考として、元のログと照らし合わせてください。

プロバイダーごとの準備

Groq

API キーを作成して設定に貼り付けます。キーは DPAPI で暗号化して保存されます。

GitHub Copilot

Copilot CLI をインストール（npm install -g @github/copilot）して copilot login を実行するか、設定にトークンを貼り付けます。Copilot のサブスクリプションが必要です。

ローカルLLM

設定から llama.cpp とモデルをダウンロードします。Q4_K_M は約 5.24 GiB なので、ディスクとメモリに余裕を持たせてください。

ヒント：PAT の URL 事前入力機能は 2026-05 に GitHub のドキュメントから削除されたため、リンクで項目が自動入力されない場合があります。上記の手動手順で設定してください。
