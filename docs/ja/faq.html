FAQ

プライバシー・互換性・ライセンスなどのよくある質問。

よくある質問

ログ全体が送信されますか？

いいえ。先に整理（ノイズ除去・スタック折りたたみ）と個人情報のマスクを行い、文字数にも上限があります。送信前にプレビューできます。ローカルLLMなら外部サーバーには一切送られません。

Forge / NeoForge に対応していますか？

ヘッダーは解析できます。ただし Forge / NeoForge の latest.log には通常完全な Mod 一覧がなく、crash-report がある場合のみ補完を試みます。

なぜ GitHub ルートは Copilot CLI を使うのですか？

以前使っていた GitHub Models は 2026-07-30 に終了し、Copilot にはトークンで直接呼べる公開チャットエンドポイントのドキュメントがありません。公式のプログラム用入口は Copilot CLI なので、アプリはそれを子プロセスとして実行します。

ローカルモデルが大量の思考を出力する？

このモデルは先に think ブロックを出力しますが、アプリが自動的に非表示にします。

別のローカルモデルを使えますか？

はい。「設定 → ローカルLLM → 詳細」でダウンロード URL を変更できます。

macOS / Linux で使えますか？

Qt を使っており Windows 以外でもコンパイルできます（作者は Linux の Qt 6.4.2 でビルドし、UI をオフスクリーンで起動確認）。ただしキー暗号化は DPAPI 依存のため、Windows 以外ではキーの保存を拒否します。

商用利用できますか？

PolyForm Shield は使用・改変・配布を許可しますが、本ソフトウェアと競合する製品やサービスの提供は禁止です。詳細はライセンスページを参照してください。法的助言ではありません。
