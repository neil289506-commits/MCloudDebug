プライバシーと安全性

キーの暗号化方式、マスク範囲、ユーザー自身で確認すべきこと。

キーの保存方法

API キーと PAT は Windows DPAPI（CryptProtectData + アプリ固有の entropy）で暗号化され、暗号文（Base64）が %APPDATA%\MCDebugger\settings.ini に保存されます。復号できるのは同じ Windows アカウントのみです。

Windows 以外では保存を拒否します。平文へのフォールバックはしません。

送信される内容

  • 整理・マスク後のログ要約（既定上限 14,000 文字）
  • クラッシュ報告の要点
  • ローカルLLM選択時は、アプリと 127.0.0.1 の間でのみデータが流れます

ユーザー側で行うこと

マスクはルールベースで、完全な匿名化は保証できません。サーバーアドレス、独自パス、チャット内容などが残る可能性があります。送信前にプレビューを確認してください。
