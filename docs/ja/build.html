ソースからビルド

Qt Creator または CMake でソースからコンパイルします。

Qt Creator

  1. CMakeLists.txt を開く
  2. Kit は Desktop Qt 6.x MSVC2022 64-bit を選択
  3. ビルドして実行

使用するのは Qt Widgets と Network のみで、Windows では crypt32 もリンクします。最低要件は Qt 6.4 です。

コマンドライン

git clone https://github.com/neil289506-commits/MCloudDebug.git
cd MCloudDebug
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_PREFIX_PATH="<Qt path>"
cmake --build build --config Release --parallel

配布用パッケージ

windeployqt --release --no-translations --compiler-runtime MCDebugger.exe

CI

v* タグを push すると、CI がソースからビルドして MCloudDebug-Windows-AMD64.zip を Release に公開します。GitHub Actions は windows-2022 でビルドします。aqtinstall が現在 Qt 6.11.x を取得できないため、6.11.2 / 6.11.3 / 6.11.1 の順に試し、使えなければ 6.10.3 にフォールバックします。
