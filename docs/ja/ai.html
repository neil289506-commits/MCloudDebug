ローカルLLMの詳細

  • 既定のモデルは empero-ai/Qwythos-9B-Claude-Mythos-5-1M-GGUF（9B 推論モデル、Q4_K_M 推奨）。別のモデルを使う場合は「設定 → ローカルLLM → 詳細」でダウンロード URL を変更します。
  • モデルは回答前に <think>…</think> を出力しますが、アプリが非表示にします（</think> のみの場合にも対応）。
  • サンプリングはモデルカードの推奨値：temperature 0.6、top_p 0.95。

llama.cpp のダウンロード方法

ggml-org/llama.cpp の releases/latest は現在、nightly-tag.txt だけを含む「ポインタ release」を指しており、実際のバージョンはそのファイルに書かれています。アプリの処理は次のとおりです：

  1. releases/latest に HEAD リクエストしてポインタのタグを取得
  2. nightly-tag.txt をダウンロードして実際のバージョンを読む
  3. ハードウェアに応じて Vulkan / CPU / CUDA 12.4 の Windows zip 名を組み立てる（CUDA は cudart も取得）
  4. PowerShell の Expand-Archive で解凍

nightly-tag.txt が存在しない場合は、リダイレクト先のタグにフォールバックします。

GitHub ルートは GitHub Copilot（Copilot CLI 経由）

以前の GitHub ルートが呼んでいた GitHub Models は 2026-07-30 に終了しました。現在は公式 copilot CLI を子プロセスとして実行します（インストール：npm install -g @github/copilot）。既定モデルは auto、shell とファイル書き込みツールは常に拒否します。設定のモデル ID 一覧は公式の表示名から導いたもので、一つずつ検証してはいません。任意の ID を入力でき、プランで使えるモデルは CLI 内の /model で確認してください。

プロンプトルール

設定 → プロンプトルール で、Groq と GitHub Copilot のシステムプロンプトに 3 つのルール（Web を検索、推測しない（分からなければ分からないと言う）、深く考える）を追加します。各ルールは無効にできます。検索ルールは、そのルートとモデルに実際に検索ツールがある場合だけ追加されます（Groq の gpt-oss 系は内蔵 browser_search、Copilot は Web アクセスを許可した場合）。Groq の既定モデルは openai/gpt-oss-120b（推論強度は高）です。
