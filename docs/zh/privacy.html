隱私與安全

金鑰加密方式、遮蔽範圍與你該自己確認的事。

金鑰如何保存

API Key 與 PAT 以 Windows DPAPI（CryptProtectData + 應用程式專屬 entropy）加密，密文（Base64）寫在 %APPDATA%\MCDebugger\settings.ini。只有同一個 Windows 帳號能解開。

非 Windows 平台會拒絕儲存，不會退回明文。

會送出什麼

  • 整理並遮蔽後的 log 摘要（預設上限 14,000 字元）
  • 崩潰報告的重點段落
  • 選本地 LLM 時，內容只在本機與 127.0.0.1 之間傳遞

你該自己做的事

遮蔽是規則式的，無法保證完全匿名。伺服器位址、自訂路徑、聊天內容等仍可能殘留，送出前請檢查預覽。
