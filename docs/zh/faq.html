常見問題

它會把我的整份 log 傳出去嗎？

不會。會先整理（去雜訊、折疊堆疊）並遮蔽個資，且有字元上限。送出前可預覽。選本地 LLM 則完全不經過外部伺服器。

支援 Forge / NeoForge 嗎？

可以解析標頭。但 Forge / NeoForge 的 latest.log 通常沒有完整 Mod 清單，有 crash-report 時才會嘗試補上。

為什麼 GitHub 管道不是 Copilot？

公開、可用 PAT 呼叫的推論 API 是 GitHub Models。沒有找到文件化的 Copilot Chat 公開端點，所以不假裝支援。

本地模型會輸出一堆思考內容？

該模型會先輸出 think 區塊，程式會自動隱藏。

可以換別的本地模型嗎？

可以，在「設定 → 本地 LLM → 進階」修改下載網址。

能在 macOS / Linux 用嗎？

程式碼用 Qt，非 Windows 平台可編譯（作者在 Linux 用 Qt 6.4.2 編譯並離屏啟動過 UI），但金鑰加密依賴 DPAPI，非 Windows 會拒絕儲存金鑰。

授權可以商用嗎？

PolyForm Shield 允許使用、修改、散布，但不可用來提供與本軟體競爭的產品或服務。細節見授權頁；這不是法律意見。
